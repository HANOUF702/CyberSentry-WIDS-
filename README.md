# CyberSentry 🛡️ – Wireless Intrusion Detection System (WIDS)

An offline, hardware-integrated Wireless Intrusion Detection System (WIDS) that combines **ESP32 & Arduino microcontrollers** with a **Python-driven Machine Learning engine** to detect 802.11 management frame attacks (specifically Wi-Fi Deauthentication / DoS attacks) with 100% accuracy.

---

## 📌 Project Overview
CyberSentry provides real-time Wi-Fi threat detection and automated incident response using deep packet analysis and machine learning. Designed for offline operational resilience, it captures 802.11 management frames via low-cost microcontrollers, extracts Indicators of Compromise (IOCs), and visualizes threat vectors on a dynamic Streamlit dashboard.
